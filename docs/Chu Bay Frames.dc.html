Quán Ăn Chú Bảy — menu & đặt món

Miền Tây rustic, kept quiet: cream “giấy dó” ground, banana-leaf green for actions & selection, chili-terracotta reserved for the one primary CTA per screen (Đặt món / Gửi đơn) and prices. Bitter (slab) for headings, Be Vietnam Pro for UI — both full Vietnamese coverage. Woven-mat texture in the hero works with or without a cover photo. Every frame below is the same live component at a fixed width — tap Thêm, steppers, tabs, search, Gửi đơn. All styling reads from :root tokens (see 9a).
